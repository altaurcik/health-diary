# Направление первой веб-версии

Дата: 2026-09-26. Разработка прямо в коде по поручению владельца.

## THESIS

Дневник как спокойный ежедневный измерительный инструмент: записать
показания и быстро прочитать их историю.

## OWN-WORLD

Тёмная поверхность #101719, панели #182326, читаемый текст #edf5f3,
мягкий акцент #7ddbc4. Manrope, табличные цифры, линейные Lucide.
Владелец прямо предпочёл тёмную тему и попросил системный вариант.

## STORY

Последние показания → запись нового измерения → динамика → расписание.
Второй экран показывает все измерения и позволяет открыть их для правки.
Профиль хранит параметры, тему и ритм измерений.

## FIRST VIEWPORT

Бренд Healthnote, явная метка демо при вымышленных данных, дата, давление,
пульс и вес с временем, крупные кнопки записи. Динамика продолжается
ниже первого экрана. Главные показатели и действия видны без прокрутки
на обычном телефоне. Нижняя навигация сохраняет положение.

## FORM

Мобильная колонка; Telegram UI для реальных полей и кнопок, авторская
композиция по задаче. Seed `1ae39663`, локальная выдача без внешнего
каталога; итоговое оформление подчинено уже заданной тёмной теме и
прямому запросу владельца строить веб-дневник. Одобренного растрового
макета нет; SVG-графики строятся по измерениям, иллюстрации не нужны.
Значимый сценарий: повторный замер связывается с первым и показывает
среднее серии, сохраняя каждый исходный замер.
