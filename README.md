# Дневник здоровья

Telegram-дневник для записи давления, пульса и веса. Бот предназначен
для напоминаний и быстрого ввода, Telegram Mini App — для основного
интерфейса, истории, графиков и настроек. Backend и база данных хранят
пользователей, измерения и расписания. LLM не используется.

Статус: требования зафиксированы, приложение пока не реализовано.

- [Описание продукта](docs/PRODUCT_BRIEF.md) — требования, предоставленные владельцем.
- [Карта проекта](PROJECT_MAP.md) — состояние, структура и открытые вопросы.
- [Инструкции](AGENTS.md) — правила работы с проектом.
- [Установленные UI-инструменты](docs/UI_TOOLS_SETUP.md) — локальные
  UI UX Pro Max, Impeccable и Telegram UI с React 18; команды и проверки.

Проверка установленных компонентов: из `frontend` выполнить
`npm ci --ignore-scripts --no-audit --no-fund --cache ../.cache/npm`,
затем `npm run check:ui`. Экранов и команды запуска приложения пока нет.

## Хранение данных

Git предназначен для кода и технической документации. Личные медицинские
записи, вложения и выгрузки хранить в исключённых каталогах `private/`,
`data/`, `uploads/` или `backups/`. Секреты хранить в `.env` или `secrets/`.
В `.env.example` допустимы только названия параметров и безопасные заглушки.
Перед коммитом проверять состав и содержимое изменений: `.gitignore`
не распознаёт личные данные внутри произвольных файлов.
