# Инструменты дизайна для Telegram Mini App

Дата исследования: 2026-09-26. Проверены README авторов и официальная
документация. На этапе исследования инструменты не устанавливались;
оценки применимости ниже — рекомендации, а не результаты сравнения качества.
Позднее в тот же день по просьбе владельца установлены UI UX Pro Max,
Impeccable и Telegram UI: актуальный статус — в [описании установки](UI_TOOLS_SETUP.md).

## Требование владельца

Основной сценарий — Telegram Mini App на телефоне в вертикальной ориентации.
Проектировать сначала мобильные экраны; размеры должны адаптироваться
к доступному окну, клавиатуре и другим ориентациям.

## Первоначальная рекомендация

Начать с UI UX Pro Max для правил оформления и Telegram UI для компонентов,
если выбираем React. Impeccable рассмотреть для последующей проверки экранов.
Не подключать одновременно несколько библиотек базовых элементов без
конкретной необходимости. shadcn/ui — альтернативная основа, 21st —
дополнительный каталог; Figma нужен при выборе отдельного процесса макетов.

Приоритет имеет контекст Telegram: общие советы skills о необычных шрифтах,
крупных заголовках или декоративных эффектах не должны ухудшать знакомое
поведение, читаемость цифр и скорость ввода измерений.

Поиск по каталогу плагинов по названиям UI UX Pro Max, Impeccable, 21st,
shadcn не вернул точных совпадений; среди результатов была Figma (не установлена).
Это ограничение выдачи поиска, а не доказательство отсутствия интеграций.

## Направление мобильного интерфейса

[Telegram рекомендует](https://core.telegram.org/bots/webapps#design-guidelines)
mobile-first адаптивность, знакомое поведение компонентов, доступные подписи,
реакцию на тему и соблюдение safe area/content safe area.

Предлагаемые проектные правила, ещё не реализованы:

- Основной макет — одна колонка, ориентир 390 CSS px; проверять 320, 360,
  390 и 430 px, увеличение текста и открытую клавиатуру.
- Главные экраны: «Сегодня», «История», «Настройки»; навигация снизу.
- Крупные значения давления/пульса/веса, заметное действие «Записать»;
  основные зоны нажатия около 44–48 CSS px.
- График занимает ширину экрана; подробности замера открываются нажатием.
- Светлая и тёмная темы, обработка safe area и изменения высоты окна.
- На компьютере сохранять удобную ширину содержимого; не блокировать
  поворот телефона ради вертикального макета.

Следующий шаг: выбрать визуальное направление и сделать один прототип
экрана «Сегодня» плюс форму измерения на демонстрационных данных.
