## Назначение

Telegram-дневник здоровья для давления, пульса и веса. Бот — напоминания
и быстрый ввод; Telegram Mini App — первоначальная настройка, ввод,
история, графики, статистика и настройки. Backend и база данных —
пользователи, измерения и расписания. LLM не нужен.

Источник требований — [описание продукта](docs/PRODUCT_BRIEF.md),
предоставленное владельцем 2026-09-26 в файле
`telegram_health_diary_summary.md`. Сохранено без изменений; описывает
целевое поведение, а не готовую реализацию.
Общая навигация по рабочей директории — в [общей карте](../PROJECT_MAP.md).
Ссылки на `../PROJECT_MAP.md` и `../SERVER_MAP.md` относятся к локальному
окружению владельца: эти файлы находятся вне данного Git-репозитория.

## Работа с Git

Git-команды выполнять из каталога проекта. На этом Mac использовать
`/Library/Developer/CommandLineTools/usr/bin/git` (обычный системный Git
ранее блокировался лицензией Xcode; см. общую карту).
Проверка изменений: `git status --short`, `git diff`, `git diff --cached`.
Исключения проверять через `git check-ignore -v путь`.
`origin`: `https://github.com/altaurcik/health-diary.git`.
Отправка коммитов: `git push`; получение обновлений: `git pull --ff-only`.
Корень Git — только `health-diary/`; соседние проекты, общая карта VPN
и серверные реквизиты в этот репозиторий не входят.
