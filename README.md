# Дневник здоровья

Telegram-дневник для записи давления, пульса и веса. Бот предназначен
для напоминаний и быстрого ввода, Telegram Mini App — для основного
интерфейса, истории, графиков и настроек. Backend и база данных хранят
пользователей, измерения и расписания. LLM не используется.

Статус: первая самостоятельная веб-версия реализована локально.
Сначала разрабатываем самостоятельную веб-версию для мобильного браузера,
затем подключаем её к Telegram Mini App, сохраняя общий интерфейс и логику.

- [Карта проекта](PROJECT_MAP.md) — состояние, структура и открытые вопросы.

- [Установленные UI-инструменты](docs/UI_TOOLS_SETUP.md) — локальные

## Запуск

Из `frontend` выполнить `npm ci --ignore-scripts --no-audit --no-fund`,
затем `npm run dev`. Открыть http://127.0.0.1:5173/.
Нужен Node `^20.19.0 || >=22.12.0`.

`npm run build` — production-сборка, `npm test` — тесты логики,
`npm run check:ui` — проверка компонентов. Возможности и ограничения:
[первая веб-версия](docs/WEB_V1.md).

Сайт начинает с обозначенного деморежима. «Начать свой» создаёт чистый
дневник с сохранением только в этом браузере. Есть запись/изменение/удаление,
история, графики, серии измерений, профиль, расписания и экспорт JSON.
Темы: тёмная, светлая, системная. Синхронизации, backend, фоновых уведомлений
и подключения Telegram пока нет. На DuckDNS ещё не размещён.

## Хранение данных

Git предназначен для кода и технической документации. Личные медицинские
записи, вложения и выгрузки хранить в исключённых каталогах `private/`,
`data/`, `uploads/` или `backups/`. Секреты хранить в `.env` или `secrets/`.
В `.env.example` допустимы только названия параметров и безопасные заглушки.
Перед коммитом проверять состав и содержимое изменений: `.gitignore`
не распознаёт личные данные внутри произвольных файлов.
