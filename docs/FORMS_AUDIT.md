# Проверка экранов ввода — 2026-09-27

Первый запуск вынесен из длинного профиля в `WelcomeForm.jsx`:
«Пропустить» у заголовка, необязательные рост и вес, кнопка «Начать».
Пропуск сохраняет пустой профиль через тот же onSave/API, а не просто меняет экран.
Ни темы, ни расписаний, ни разрешения писать на этом экране нет. После старта
напоминания настраиваются в профиле; на пустой главной остаётся короткая ссылка.

Профиль разделён на «О вас», «Напоминания», «Ещё». Часовой пояс в раскрываемом
блоке. Разрешение сообщений доступно только в разделе напоминаний. Тема и
экспорт/импорт — в «Ещё». Редактор будильника скрывает список и лишние заголовки;
сохранение/отмена доступны над нижним меню. Исправлено переполнение дней на 320 px.

Все новые поля — 48 px, текст не менее 16 px. Формы давления/веса сохраняют
предыдущую компактную компоновку. Поля не уменьшаются ради попытки уместить
всю форму при открытой клавиатуре: при малой высоте разрешена прокрутка.

## Фактически проверено

Отдельные локальные origin 127.0.0.1:5174 и localhost:5174 использовались только
для синтетических данных; production-профиль не менялся.

| Экран | Проверка |
| --- | --- |
| Первый запуск, 320×568 | Весь экран без прокрутки, «Пропустить» виден сразу, нет блока напоминаний |
| Пропуск | Пустой дневник сохраняется, после перезагрузки открывается главная |
| Начало с данными | Рост 178 и вес 76,4 сохраняются; вес виден после перезагрузки |
| Профиль «О вас», 320×568 | Поля и сохранение видны, кнопка над нижней навигацией; рост сохраняется |
| Часовой пояс | При раскрытии и фокусе поле находится выше строки действий |
| Новый будильник, 320×568 | Нет списка над формой; все семь дней в пределах ширины, изменение дней сохраняется |
| «Ещё» | Оформление и экспорт доступны отдельно от личных полей; импорт перенесён в этот же раздел |
| Вес | Сохранение синтетических 76,4 и комментария прошло |
| Давление | Сохранение синтетических 128/82 прошло |

Реальная экранная клавиатура Telegram iOS/Android не эмулировалась. Проверки
малой высоты 360 px для форм измерений описаны в WEB_V1.md; для новых экранов
подтверждены браузерные размеры и фокус, не нативные всплывающие date/time picker.
Импорт JSON не выполнялся на личном аккаунте в рамках этой проверки.
