# Первая самостоятельная веб-версия

Проверено 2026-09-26. Реализовано локально, серверное развёртывание не выполнялось.

## Возможности

- «Сегодня»: последние давление, пульс и вес с временем, кнопки записи,
  динамика, расписание, последние измерения.
- Ввод давления, необязательного пульса, веса, комментария и даты/времени.
  Редактирование, удаление с подтверждением, повторный замер и среднее серии.
- История: давление/пульс/вес; 7/30/90/365 дней или всё время, среднее,
  минимум/максимум, реальные точки графика и список записей.
- Для 90 дней используется агрегирование по дням, для года — по неделям.
  Длинная история также агрегируется. Статистика считается по исходным
  измерениям, а не по средним точкам графика.
- Профиль: дата рождения, пол, рост, часовой пояс; поля можно заполнить позже.
  Начальный вес при создании дневника сохраняется первой записью.
- Тёмная тема по умолчанию, светлая и «Система». Системный режим использует
  prefers-color-scheme и реагирует на изменение; выбор хранится отдельно.
- Независимые расписания давления и веса, ежедневные/по дням недели/
  ежемесячные (дни 1–28). Для давления возможны два времени в день.
  Видимые напоминания поддерживают запись, перенос на 30 минут и пропуск.
- Экспорт всех записей и настроек в локальный JSON-файл.

## Хранение и границы

Без сохранённого профиля сайт показывает явно обозначенный деморежим
с вымышленными данными. Его изменения существуют только в памяти и
сбрасываются при перезагрузке. «Начать свой» создаёт чистый дневник.

Личные данные сохраняются в localStorage текущего origin:
`healthnote.diary.v1`, тема — `healthnote.theme`. Данные не передаются на
сервер; внешних шрифтовых запросов, аналитики и LLM нет. Node/Vite нужны
для разработки и сборки, приложение работает в браузере.

Очистка данных браузера удалит историю; синхронизации, серверной копии,
входа и импорта JSON пока нет. Ошибки чтения не перезаписывают исходные
данные; ошибки записи показываются пользователю. Смена адреса/порта сайта
создаёт другой origin и отдельное хранилище. Перед переносом нужен экспорт
и будущий механизм импорта/миграции.

Напоминания отображаются, пока сайт открыт. Нет фоновых браузерных push,
Telegram-сообщений или гарантированной доставки при закрытом сайте.
Указанные числовые границы ввода — техническая проверка, не медицинская
классификация. Диагнозы и оценки показателей не выводятся. BMI — только расчёт.

## Запуск

Из `health-diary/frontend`:

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run dev
npm run build
npm run preview
npm test
npm run check:ui
```

Node: `^20.19.0 || >=22.12.0`; проверено на Node 23.6.1, npm 10.9.2.
Разработка: http://127.0.0.1:5173/, preview production-сборки:
http://127.0.0.1:4173/. Оба сервера слушают только loopback, strictPort=true.
Для доступа с телефона или через DuckDNS предстоит отдельное размещение.
Результат сборки — `frontend/dist/` (не в Git).

## Код

- `frontend/index.html`, `src/main.jsx` — точка входа, локальные шрифты и CSS.
- `src/App.jsx` — экраны, формы, график, настройки, обработчики действий.
- `src/data.js` — модель, валидация, localStorage, даты, периоды, статистика,
  серии, расписания и генератор синтетического демо.
- `src/styles.css` — тёмные/светлые токены и адаптивная компоновка.
- `test/data.test.js` — девять тестов логики с фиксированным временем.

## Проверено

- Production build, девять тестов и smoke-проверка Telegram UI прошли.
- Браузер: ввод давления и необязательного пульса, среднее двух замеров,
  изменение записи, отклонение перепутанных значений, удаление с подтверждением.
- На отдельном локальном тестовом origin `localhost:5173` создан профиль
  с синтетическим весом: перезагрузка сохранила запись, рост и выбор «Система».
  Основной предпросмотр `127.0.0.1:5173` оставлен в деморежиме.
- Визуально проверены тёмная/светлая темы, форма, ширины 320/390 и 1280 CSS px;
  горизонтального переполнения на проверенных экранах нет. Клавиатурный
  выбор точки графика ArrowLeft проверен в браузере.
- Impeccable detector по `frontend/src` вернул пустой список находок.
  Отдельное ревью указало три исправления: подпись на 320 px, контраст
  разделителя давления и высоты зон нажатия. Исправления внесены;
  отдельный reviewer подтвердил все три как resolved, disposition: ship
  в границах этих исправлений. Это не сертификат всего приложения.
- Ошибки хранилища, временные зоны, пропуски при переходе DST, календарные
  периоды, отсутствие пульса, агрегация, серии, расписания и BMI проверены
  модульными тестами. Неверная временная зона не вызывает падение формы.

Не проверены на реальном устройстве: экранная клавиатура iOS/Android,
Telegram WebView и его темы/safe areas. Нет проверки фоновых уведомлений,
потому что их ещё нет. Снимки UI и состояние ревью локально в `.impeccable/review/`.
