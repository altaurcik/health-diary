# Дневник здоровья — карта проекта

Дата создания и проверки: 2026-09-26.

## Назначение

Telegram-дневник здоровья для давления, пульса и веса. Бот — напоминания
и быстрый ввод; Telegram Mini App — первоначальная настройка, ввод,
история, графики, статистика и настройки. Backend и база данных —
пользователи, измерения и расписания. LLM не нужен.

Порядок разработки уточнён владельцем 2026-09-26: сначала самостоятельная
веб-версия с вертикальным мобильным интерфейсом, затем подключение этой же
версии к Telegram Mini App. На первом этапе дневник открывается в обычном
браузере без обязательного Telegram-контекста.

Источник требований — [описание продукта](docs/PRODUCT_BRIEF.md),
предоставленное владельцем 2026-09-26 в файле
`telegram_health_diary_summary.md`. Сохранено без изменений; описывает
целевое поведение, а не готовую реализацию.
Общая навигация по рабочей директории — в [общей карте](../PROJECT_MAP.md).
Ссылки на `../PROJECT_MAP.md` и `../SERVER_MAP.md` относятся к локальному
окружению владельца: эти файлы находятся вне данного Git-репозитория.

## Зависимости, конфигурация, запуск и проверки

Для UI установлены React/React DOM 18.3.1 и Telegram UI 2.1.13.

приложения пока нет. Установка зависимостей и проверка из `frontend`:
`npm ci --ignore-scripts --no-audit --no-fund --cache ../.cache/npm`,
`npm run check:ui`. Проверка не запускает Mini App.
Команды skills и все версии — в [описании установки](docs/UI_TOOLS_SETUP.md).
Серверная инфраструктура для проекта не создавалась. Общие сведения
о существующем сервере — в [SERVER_MAP.md](../SERVER_MAP.md).

Владелец подтвердил 2026-09-26, что будем использовать именно его.
Планируемый адрес Mini App: `https://healthnote-bot.duckdns.org`.
Владелец предоставил скриншот регистрации этого домена;
на скриншоте указан IP из карты сервера. Это не проверка DNS или HTTPS.

не выполнены. В описании предложены Caddy или nginx — выбор не сделан.

## Работа с Git

Git-команды выполнять из каталога проекта. На этом Mac использовать
`/Library/Developer/CommandLineTools/usr/bin/git` (обычный системный Git
ранее блокировался лицензией Xcode; см. общую карту).
Проверка изменений: `git status --short`, `git diff`, `git diff --cached`.
Исключения проверять через `git check-ignore -v путь`.
`origin`: `https://github.com/altaurcik/health-diary.git`.
Отправка коммитов: `git push`; получение обновлений: `git pull --ff-only`.
Корень Git — только `health-diary/`; соседние проекты, общая карта VPN
и серверные реквизиты в этот репозиторий не входят.

## Принятые решения

- Название проекта: «Дневник здоровья»; каталог: `health-diary/`.
- Домен: `healthnote-bot.duckdns.org`, провайдер DuckDNS; выбор подтверждён
  владельцем 2026-09-26. Использовать при настройке HTTPS и Telegram Mini App.
- Подробности проекта вести здесь, в общей карте поддерживать навигацию.
- UI UX Pro Max, Impeccable и Telegram UI выбраны владельцем 2026-09-26.
  Skills, зависимости и кеши установки держать только в health-diary;
  в Git входят skills/лицензии и manifests, но не node_modules/кеши.
- Фактическое состояние отделять от планов, отмечать дату проверки.
- 2026-09-26: сначала самостоятельный сайт, затем Telegram Mini App.
  Использовать общую кодовую базу; Telegram SDK, авторизацию, тему и
  управление окном подключать через отдельный слой интеграции.
  UI-компоненты и логика измерений не должны зависеть от наличия Telegram.
- Объём продукта: давление, пульс и вес; отдельные роли бота и Mini App.
- 2026-09-26: владелец указал основной формат — вертикальный интерфейс
  Telegram Mini App на телефоне. Проектировать сначала для мобильного экрана;
  рекомендации и предлагаемые размеры проверки — в подборке инструментов UI.
- Ввод стандартных форматов, статистику, средние, BMI и напоминания
  реализовать обычной программной логикой без LLM.
